      이벤트 CSV 받기↓

      앱과 공유 뷰어가 보낸 화면 보기·버튼 누름(POST /api/v1/events)을 세션별로 묶어, 새로 만들기 흐름의 단계마다 이른 세션 수를 셉니다. 세션마다 앞 단계 뒤에 처음 나온 이벤트만 세고, 시간은 앞 단계에서 걸린 시간의 중앙값입니다. 마지막 단계는 작업으로 만든 모델의 배치만 셉니다(저장한 강아지를 놓은 것은 아래 '불러오기 퍼널'). 기간은 서버가 받은 시각 기준, 30초마다 갱신. 이름과 속성은 docs/METRICS.md §6.
