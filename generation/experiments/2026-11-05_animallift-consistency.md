# 2026-11-05 AnimalLift 같은 개 일관성 실험

| 항목 | 값 |
|---|---|
| 날짜 | 2026-11-05 |
| 담당 | Unity 트랙 (생성 품질 조사) |
| 환경 | RTX 4060 Ti 8GB, WSL2 Ubuntu / AI 생성 강아지 5마리 × 10상황 × 전처리 3조건 |
| 상태 | [실험 결과] |

같은 개를 여러 상황에서 찍었을 때 AnimalLift 결과가 "같은 개"로 나오는지, 서버 전처리가 일관성을 높이는지 확인했다.

## 요약

1. **개를 구분하는 건 거의 전부 털색이다.** 털색 AUC 0.98, 털 길이 0.88, 모양 0.64. AnimalLift는 체형을 사진에서 거의 읽지 못하고 비슷한 템플릿을 낸다.
2. 배경 제거가 세 조건 중 가장 일관적이지만(식별 90%) 차이는 작다. 통계적으로 유의한 개선은 털 길이뿐이다.
3. 넓은 각도(광각), 뒷모습, 웅크려 잠, 사람이 안음이 가장 나쁘고, 반신·위에서 찍은 사진이 가장 좋다.
4. 서버 검사가 놓친 실패가 있다. 다른 개와 함께 찍힌 사진(P04)은 통과했지만 털색이 다른 개 색으로 바뀌었다.

## 방법

| 항목 | 값 |
|---|---|
| 사진 | AI 생성 강아지 5마리(P01~P05) × 상황 10종 = 50장 |
| 상황 | 뒷모습, 흐림, 상반신 근접, 웅크려 잠, 어두운 실내, 반신, 사람이 안음, 위에서 찍음, 광각, 다른 개와 함께 |
| 조건 | 원본(AnimalLift가 정사각형으로 늘림) / 크롭패딩(YOLOX 크롭, 배경 유지) / 배경 제거(U2Net, 서버 기본값) |
| 비교 | 같은 개 쌍 225개 vs 다른 개 쌍 1,000개 |
| 식별 | 사진 하나를 빼고, 각 개의 나머지 결과 중앙값과 비교해 가장 가까운 개를 맞히는 비율 (우연 20%) |

## 결과 (털색·털 길이·모양 종합 특징)

| 조건 | 같은/다른 개 거리 비 | AUC | 같은 상황끼리 AUC | 식별 |
|---|---:|---:|---:|---:|
| 원본 | 0.57 | 0.903 | 0.864 | 86% |
| 크롭패딩 | 0.54 | 0.912 | 0.878 | 82% |
| 배경 제거 | 0.50 | **0.919** | **0.893** | **90%** |

특징별(배경 제거 기준): 털색 AUC 0.98 · 식별 96%, 털 길이 AUC 0.88 · 식별 74%, 모양 AUC 0.64 · 식별 58%.

## 세부 관찰

- 모양은 개마다 별 차이가 없다. 다른 개끼리 중앙값 1.7~1.9%, 같은 개끼리 1.2~1.4%.
- 배경 제거의 털 길이 개선은 50장 중 43장(Wilcoxon p < 0.001). 털색 개선은 p = 0.12, 식별 86→90%는 사진 2장 차이(McNemar p = 0.69)로 유의하지 않다.
- 서버가 거절하는 흐림·어두운 실내 사진은 오히려 일관성이 상위권이었다(배경 제거 식별 100%). 다만 실험의 흐림은 선명도 41~46으로 기준(50) 바로 아래인 약한 흐림이다.
- 개마다 차이가 크다. 검은 개(P04)가 가장 안정적(색 ΔE 약 4~7)이고, 얼룩 무늬(P05)와 붉은 털(P01)이 가장 흔들린다(약 18~22).

## 한계

- 5마리, AI 생성 사진. 식별률 4%p 차이는 사진 2장이다.
- 반신 사진은 개마다 자세가 다르다.
- [방해 요소 실험](2026-11-05_animallift-robustness.md)의 "배경 제거는 색을 평균적으로 개선하지 않는다"는 한 마리 결과였다. 5마리에서는 약한 개선 경향이 있으나 유의하지 않다.

## 앱·서버에 주는 의미

- 털색이 개 정체성의 대부분이므로, 앱에서 털 셰이딩이 색을 바꾸지 않게 하는 것이 중요하다([FUR_RENDERING.md](../../unity/docs/FUR_RENDERING.md) 알려진 한계).
- 서버 검사에 "다른 개가 붙어 있음"을 더 엄격하게 거르는 규칙, 촬영 가이드(전신, 정면·측면)를 검토한다.
