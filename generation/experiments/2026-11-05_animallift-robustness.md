# 2026-11-05 AnimalLift 방해 요소 실험

| 항목 | 값 |
|---|---|
| 날짜 | 2026-11-05 |
| 담당 | Unity 트랙 (생성 품질 조사) |
| 환경 | RTX 4060 Ti 8GB, WSL2 Ubuntu / AnimalLift test.py, batch 1 / 공개 사진 6장 + AI 생성 포메라니안 10장 |
| 상태 | [실험 결과] |

사진에 방해 요소(흐림, 두 마리, 동물 없음, 사람·물건, 어두운 실내 등)가 있을 때 AnimalLift 결과가 어떻게 바뀌는지, 서버의 사진 검사·전처리가 도움이 되는지 확인했다.

## 요약

1. AnimalLift는 **어떤 입력에도 실패하지 않고 정상 체형의 강아지를 낸다.** 강아지가 없는 사진에서도 소파 색 강아지가 나왔다. 출력만으로는 잘못된 입력을 걸러낼 수 없으므로 서버의 입력 검사(동물 없음·두 마리·흐림)가 필요하다.
2. 같은 개라도 사진에 따라 모양 차이가 0.6~2.2%로, 서로 다른 개 사이의 차이(중앙값 1.79%)와 겹친다. **어떤 사진을 고르느냐**가 전처리보다 결과에 훨씬 큰 영향을 준다.
3. 크롭 + 패딩(늘리지 않기)은 체형을 조금 개선한다. 배경 제거는 털 색을 평균적으로 개선하지 못했다(사진에 따라 좋아지기도 나빠지기도 함).
4. 흰 장모견은 서버 검사를 통과하는데 짙은 갈색·회색으로 나온다. 실제 사용자가 겪을 문제다.

## 공통 방법

- RTX 4060 Ti 8GB, AnimalLift 추론(batch 1), 사진당 1회
- AnimalLift 결과는 모든 개가 같은 토폴로지(정점 4,310개)라서 정점끼리 직접 비교한다.
- **모양 이탈/차이** = 평균 정점 거리 ÷ 몸 대각선(%). 기준: 깨끗한 사진 10장 결과의 평균 모양 이탈 0.73~2.04%, 서로 다른 개 10마리끼리 차이 최소 0.88% · 중앙값 1.79% · 최대 3.80%
- **서버 판정**: 백엔드 사진 검사(PhotoCheck)·배경 제거(Cutout)를 Python으로 재현해 같은 모델 파일(YOLOX-S, U2Net)로 판정했다.

## 1차: 서로 다른 개 6장 (공개 사진)

| 사진 | 서버 판정 | 원본: 모양 이탈 | 배경 제거: 모양 이탈 | 관찰 |
|---|---|---|---|---|
| R1 앉은 하운드, 목줄 | 통과 | 0.92% 범위 안 | 2.17% 경계 초과 | 배경 제거가 탄 무늬를 더 살림 |
| R2 흔들린 얼굴 근접 | 흐림 거절 | 4.26% 이상 | 3.76% 이상 | 몸이 안 보여 가장 크게 이탈 |
| R3 검은 개, 막대·사슬 | 통과 | 1.57% 범위 안 | 1.48% 범위 안 | 둘 다 양호 |
| R4 흰 장모견, 풀·잘림 | 통과 | 0.65% 범위 안 | 2.91% 이상 | **흰 개가 두 조건 모두 갈색·회색으로 나옴** |
| R5 물속 두 마리 | 두 마리 거절 | 2.07% 이상 | 2.13% 이상 | 두 개의 털 색이 섞임 |
| R6 강아지 없음 | 동물 없음 거절 | 1.21% 범위 안 | — | **소파 색의 정상 체형 강아지 생성** |

## 2차: 같은 개(포메라니안, AI 생성) 10가지 상황, 원본 입력

기준 사진 P09 대비 모양 차이와, 입력 털 색조(25~28°) 대비 결과 색조.

| 사진 | 모양 차이 | 판정 | 결과 털 색조 |
|---|---:|---|---:|
| P09 정원 (기준) | — | — | 7° (적갈색) |
| P06 뒷모습 | 2.22% | 다른 개 수준 | 26° |
| P10 어두운 실내 | 2.06% | 다른 개 수준 | 28° |
| P03 작은 개와 함께 | 1.87% | 다른 개 수준 | 26° |
| P08 광각 셀카 | 1.13% | 다른 개 최소 이상 | 12° |
| P07 엎드림·흐림 | 0.98% | 다른 개 최소 이상 | 31° |
| P02 상반신 근접 | 0.83% | 같은 개 수준 | 25° |
| P01 사람이 안음 | 0.77% | 같은 개 수준 | 20° |

| P04 웅크리고 잠 | 0.61% | 같은 개 수준 | 18° |

뒷모습·어두운 실내·다른 개 동반이 가장 해롭다. 털 길이 맵은 10장 모두 몸 대비 32~39%로 일정했다(장모 특성 유지). 색은 사진마다 크게 흔들렸다(7~31°).

## 3차: 2차 사진을 서버 전처리 조건으로 (원본 / 크롭패딩 / 배경 제거)

10장 모두 서버 검사를 통과했다.

| 지표 | 원본 | 크롭패딩 | 배경 제거 |
|---|---:|---:|---:|
| 평균 모양 이탈 | 2.26% | **1.93%** | 2.03% |
| "이상" 판정 수 (> 2.04%) | 7/10 | **5/10** | 5/10 |
| 털 색조 평균 오차 (입력 26.5° 기준) | **5.8°** | 6.5° | 7.1° |

- 전처리에 따른 모양 변화(원본 대비)는 0.11~1.23%로, 사진 상황에 따른 차이(0.6~2.2%)보다 작다.
- 배경 제거 결과 특이점: 사람 팔·손이 개와 함께 남음(P01), 붙어 있는 다른 개가 함께 남음(P03), 얼굴만 남음(P08), 털 가장자리 초록 테두리(P09).
- 어두운 실내(P10)는 원본에서는 밝게 보정되어 나왔지만, 배경을 지우면 어둡고 붉게 나왔다.
