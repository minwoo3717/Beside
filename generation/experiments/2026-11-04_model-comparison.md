# 2026-11-04 사진 한 장 → 3D 생성 모델 비교

| 항목 | 값 |
|---|---|
| 날짜 | 2026-11-04 |
| 담당 | Unity 트랙 (생성 품질 조사) |
| 환경 | RTX 4060 Ti 8GB, WSL2 Ubuntu / 사진 10장 1024 px / batch 1 |
| 상태 | [실험 결과] |

AnimalLift를 계속 쓸지 판단하려고, 같은 GPU에서 쓸 수 있는 공개 모델 3개의 생성 시간·메모리·출력 형태를 비교했다.

## 요약

- 생성 시간은 SF3D(0.67 s) < TripoSR(1.63 s) < AnimalLift(5.31 s).
- **AnimalLift만 고정된 동물 토폴로지(정점 4,310개)와 털 정보(hair.npz)를 준다.** 그래서 리깅을 옮겨 붙일 수 있고 털 길이·결을 개마다 쓸 수 있다. 나머지 둘은 결과마다 메시 구조가 달라 리깅·애니메이션이 어렵다.
- 현재 파이프라인은 AnimalLift를 쓴다. 생성 시간은 5초대로 가장 느리지만, 애니메이션과 털에 필요한 정보를 주는 모델은 AnimalLift뿐이다.

## 조건

| 항목 | 값 |
|---|---|
| GPU | NVIDIA RTX 4060 Ti 8GB, WSL2 Ubuntu |
| 입력 | 강아지 사진 10장. 배경 제거(rembg isnet-general-use, 1장은 BiRefNet), 정사각 크롭, 1024 px |
| 시간 | 1장당 시간 = (N장 실행 시간 − 1장 실행 시간) ÷ (N − 1). 모델 로딩 시간 제외 |
| 반복 | N = 10장 × 5배 복제 = 50장, 3라운드, 라운드마다 모델 순서 무작위, 실행 사이 20초 휴식 |
| VRAM | 실행 중 nvidia-smi 최대값 − 실행 직전값 (PyTorch 캐시 포함이라 실제 필요량보다 큼) |

## 결과

| 모델 | 1장당 생성 시간 (중앙값) | 라운드 범위 | 최대 VRAM 점유 | 삼각형 수 (중앙값, 범위) | 색 표현 | 털 | 토폴로지 |
|---|---:|---:|---:|---|---|---|---|
| AnimalLift | 5.31 s | 5.28–6.17 | 7,593 MB | 7,774 (고정) | UV 텍스처 1024² | 털 맵(hair.npz) | 모든 결과 동일 (정점 4,310) |
| SF3D | 0.67 s | 0.65–0.73 | 7,313 MB | 20,042 (17,140–26,288) | UV 텍스처 1024² | 없음 | 결과마다 다름 |
| TripoSR | 1.63 s | 1.63–1.75 | 5,699 MB | 103,542 (78,839–130,099) | 정점 색상 | 없음 | 결과마다 다름 |

## 재현성

- 1차 측정(N = 10, 복제 없음)에서 AnimalLift 5.68 s, TripoSR 1.45 s로 순위·크기가 같았다. SF3D는 로딩 시간 흔들림이 생성 시간보다 커서 1차에서는 잴 수 없었고(−0.25 s), 50장으로 늘려 해결했다.
- 같은 사진을 반복해 넣으면 세 모델 모두 같은 형상을 낸다(AnimalLift 15/15 쌍, TripoSR 40/40 쌍 정점까지 동일. SF3D는 형상 동일, UV 펼치기만 실행마다 달라 GLB 정점 수가 수십 개 차이).
